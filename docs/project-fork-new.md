# Project Fork New

## 0a10d81 - feat: add conditional retained mail search

本次提交扩展了普通邮箱本地保留的邮件内容搜索能力，支持按账号级包含/排除条件筛用户，并优化搜索结果邮件与账号列表联动。

- 邮件搜索模式新增可展开的“排除条件”输入框，包含规则和排除规则都支持多行输入，一行一条规则。
- 包含规则按 OR 语义匹配，账号只要任一邮件命中任一包含规则即可进入候选。
- 排除规则按账号级生效，账号在同一分组、文件夹和本地保留范围内任一邮件命中排除规则即被排除。
- 支持只填写排除条件进行搜索，用于筛出“不包含某类邮件”的账号。
- 邮件搜索字段新增发件人，搜索范围包括标题、发件人、预览和去 HTML 后正文。
- 未选择账号时，右侧邮件列表显示全部命中邮件；点击命中账号后进入该账号的普通邮箱加载流程。
- 全部命中邮件列表中的“查看用户邮件”按钮会和“账号: xxx”放在同一行，并在点击后选中对应账号、同步滚动左侧账号列表到该用户。
- 邮件搜索命中账号列表保持原账号卡 UI、多选流程和更多操作菜单，只额外展示“X 封命中”。
- 刷新页面默认回到账号搜索模式，切换搜索 tab 时会同步清理右侧邮件列表状态。
- 补充后端与前端测试，覆盖包含/排除规则、排除-only 搜索、发件人匹配、原账号卡操作保留和账号滚动联动。

本次提交修复了邮件内容搜索后的命中账号列表 UI 和操作能力偏离原账号列表的问题。

- 邮件搜索命中账号卡恢复原账号列表样式，不再显示额外的 `M` 标识和“最近命中”文本。

- 邮件搜索聚合账号补充 `forward_enabled`、别名、标签、备注、创建时间和刷新状态等字段，让批量操作和原卡片信息保持一致。
- 邮件搜索模式下的批量栏按普通账号处理，避免当前分组为临时邮箱时错误隐藏刷新、导出、转发、代理和移动等按钮。
- 补充接口与前端静态测试，覆盖命中账号字段、原 more 菜单、多选入口和命中数量标签。

## 8c025ac - feat: add retained mail content search

本次提交新增了基于普通邮箱本地保留数据库的邮件内容搜索能力，并保留账号列表联动。

- 搜索区新增“账号 / 邮件”分段切换，账号模式保持原有邮箱、别名、备注和标签搜索行为。
- 邮件模式调用 `GET /api/emails/search`，搜索 `retained_normal_mail_messages` 中的标题、预览和去 HTML 后的正文。
- 邮件搜索会包含普通列表缓存和转发轮询隐藏缓存，支持后续按标题、`body_preview` 和已缓存 `body` 检索邮件。
- 邮件模式左侧展示命中账号列表，包含账号邮箱、分组、命中数量和最近命中时间。
- 未选择账号时，右侧展示全部命中邮件；点击某个命中账号后只展示该账号命中的邮件，再次点击同一账号会取消筛选并恢复全部命中邮件。
- 搜索结果邮件会携带 `account_email`、`account_id`、`folder` 和 `id_mode`，打开详情、查看 raw 和下载附件时使用结果所属账号，不依赖当前普通邮箱上下文。
- 邮件搜索模式下隐藏跨账号批量邮件操作和详情删除入口，避免误触发不适合跨账号执行的操作。
- 修复邮件搜索参数中空格被编码为 `+` 后无法命中的问题，并保持移动端切换“邮件”标签时不关闭抽屉。
- 补充分组 select 桌面端紧凑宽度和移动端可点击尺寸样式。
- 新增后端与前端静态测试，覆盖标题、预览、正文搜索、账号聚合、过滤分页、隐藏缓存命中、跨账号详情请求和移动端抽屉行为。

## 61f0121 - feat: retain forwarded poll emails

本次提交新增了邮件转发轮询写入普通邮箱本地保留的能力。

- 在 `retained_normal_mail_messages` 新增 `forward_poll_cached` 和 `forward_poll_cached_at` 字段，用于区分“转发轮询已缓存”和“普通列表已展示/确认”。
- 普通邮箱本地保留开启时，转发轮询会把候选邮件的标题、发件人、收件人、时间和 `body_preview` 写入隐藏缓存。
- 转发阶段成功取到邮件详情后，会把正文、正文类型、抄送和附件元数据补写到同一条保留记录。
- 轮询缓存的新邮件默认不提前出现在普通本地列表中；用户打开邮箱后仍按原有“点击显示”或“自动展示新邮件”逻辑处理。
- 本地搜索带标题、发件人或关键词条件时，会同时搜索普通列表缓存和转发轮询隐藏缓存，支持后续基于标题、预览和已缓存正文检索。
- 新增回归测试覆盖 schema 迁移、轮询写库、保留关闭不写库、写库失败不影响转发、新邮件提示保持以及搜索可见性。

## b7ec622 - feat: add verification code copy toggle

本次提交新增了邮件列表验证码识别与复制能力。

- 邮件列表会基于已有的 `subject`、`body_preview` 和已随列表返回的 `body` 识别验证码，不额外请求邮件详情，也不新增数据库表。
- 命中验证码时，在邮件标题右侧显示蓝色验证码按钮，按钮文本就是验证码本身。
- 点击验证码按钮会复制验证码，并阻止邮件列表行的默认打开行为。
- 验证码识别优先匹配验证码、登录代码、security code、verification code、OTP 等上下文，支持 4-8 位数字或字母数字验证码，并规避年份、账号数字和无验证码语义的普通数字。
- 常规设置新增“开启复制验证码”开关，默认开启；关闭后前端不再进行验证码识别，也不渲染复制按钮。
- 新增前端与接口测试，覆盖验证码提取、误报规避、设置默认值、设置保存、委托点击和移动端样式约束。
