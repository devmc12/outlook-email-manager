## b7ec622 - feat: add verification code copy toggle

本次提交新增了邮件列表验证码识别与复制能力。

- 邮件列表会基于已有的 `subject`、`body_preview` 和已随列表返回的 `body` 识别验证码，不额外请求邮件详情，也不新增数据库表。
- 命中验证码时，在邮件标题右侧显示蓝色验证码按钮，按钮文本就是验证码本身。
- 点击验证码按钮会复制验证码，并阻止邮件列表行的默认打开行为。
- 验证码识别优先匹配验证码、登录代码、security code、verification code、OTP 等上下文，支持 4-8 位数字或字母数字验证码，并规避年份、账号数字和无验证码语义的普通数字。
- 常规设置新增“开启复制验证码”开关，默认开启；关闭后前端不再进行验证码识别，也不渲染复制按钮。
- 新增前端与接口测试，覆盖验证码提取、误报规避、设置默认值、设置保存、委托点击和移动端样式约束。

## ff21d5e - feat: add collapsible group panel

本次提交新增了 Web 首页分组面板的桌面端折叠能力。

- 在“分组面板”右侧垂直中部新增窄折叠条，仅在悬停分组面板或键盘聚焦时显示，减少对分组列表的遮挡。
- 点击折叠条后，分组面板通过宽度动画收起，并隐藏面板内容与边框占位。
- 分组面板收起后，屏幕左侧垂直中部显示贴边展开条，点击后通过动画恢复分组面板。
- 折叠状态会写入 `localStorage`，桌面端刷新后保持用户上次选择；切换到移动端时自动禁用桌面折叠状态。
- 响应式宽度同步使用 `--group-panel-width`，避免 1200px / 1024px 桌面断点下折叠条错位。
- 增加前端静态测试，覆盖控件存在、桌面端动画样式、响应式宽度变量和折叠状态初始化逻辑。

## a89b0a3 - feat: add forwarding group labels and project map

本次提交新增了邮件转发的“附加邮箱分组”能力。

- 在“邮件转发设置”中新增“附加邮箱分组”开关，默认关闭。
- 新增设置项 `forward_include_account_group`，通过设置 API 读写并持久化到 SQLite `settings` 表。
- 转发轮询读取账号时关联 `groups` 表，拿到账号所属分组名。
- 开启后，Telegram 和企业微信转发文本会在时间后追加 `分组: xxx`。
- 开启后，SMTP 转发只在转发邮件的顶部元信息区追加分组行，不修改原邮件正文内容。
- 增加转发相关测试，覆盖默认关闭不输出分组、开启后输出账号分组的行为。
- 补充 `docs/project-map.md`，记录项目结构、技术栈、数据库表和二开注意点。
